【文件夹结构】
───────────────────────────────────────────────
  concierge/
  ├── higa.html          ← 東山民宿 正式页面（二维码指向这里）
  ├── stores.js          ← 所有数据（门店 + 民宿点位），由 admin 导出
  ├── admin.html         ← 管理后台（日常维护在这里操作）
  ├── map-bg.png         ← 首页地图背景图
  ├── images/            ← 门店图片文件夹（自行放入）

  services/images/       ← LINE 和微信二维码图片
  ├── line-qr.jpg
  └── wechat-qr.jpg


【日常维护：增加 / 修改门店】
───────────────────────────────────────────────
1. 用浏览器打开 admin.html（建议用 VS Code 的 Live Server 插件）
2. 切换到「🏪 门店管理」标签
3. 点「＋ 导入门店」→ 粘贴 Google Maps Embed URL
     注意：在 Google Maps 上把地图放大到街道级别（能看到附近街道名）
     再点「嵌入地图」复制 <iframe> 代码，URL 里 !1d 后面的数字应小于 10000
4. 系统自动提取：店名、坐标、地区、各民宿距离
5. 补填：简介、营业时间（或设置 Google Places API Key 自动获取，见下方）
6. 点「🌐 自动翻译英文/日文」
7. 上传门店图片到 images/ 文件夹，在图片字段填写路径如 images/spa1.jpg
8. 确认无误后，点「📥 导出 stores.js」→ 下载 → 覆盖 concierge/stores.js
9. 刷新 higa.html 即可看到更新


【调整门店排序】
───────────────────────────────────────────────
每家门店有两个排序数字：
  orderAll  全部列表中的位置（数字越小越靠前）
  orderCat  该分类内的位置（数字越小越靠前）

在 admin.html 门店卡片最顶部「排序」字段直接修改数字，导出即生效。


【新增民宿点位（如祇园、嵐山）】
───────────────────────────────────────────────
1. 打开 admin.html → 切换到「🏡 民宿管理」标签
2. 点「＋ 新增民宿点位」
3. 填写：
     ID       英文小写，如 gion（用于文件命名和链接参数）
     中文名   如 祇園別邸
     English  如 Gion Bettei
     日本語   如 祇園別邸
4. 粘贴该民宿的 Google Maps Embed URL → 点「提取坐标」
5. 点「📍 重新计算到所有门店的距离」→ 有坐标的门店自动更新
6. 切换回「门店管理」→ 导出 stores.js → 覆盖文件

7. 复制 higa.html → 重命名为 gion.html（或对应名称）
8. 用文本编辑器打开新文件，搜索：
       return STAYS.includes(s) ? s : 'higashiyama';
   把末尾的 'higashiyama' 改为新民宿 ID，如 'gion'
9. 生成二维码指向：https://[你的域名]/concierge/gion.html
   将二维码放在该民宿房间内

【二维码 URL 格式】
───────────────────────────────────────────────
  東山   →  https://[域名]/concierge/higa.html
  祇園   →  https://[域名]/concierge/gion.html
  嵐山   →  https://[域名]/concierge/arashiyama.html

  页面会根据文件自动识别民宿位置，客人无需任何操作。
  语言自动识别：中文手机显示中文，日文手机显示日语，其余为英文。

【Google Places API Key（可选，自动获取营业时间/简介）】
───────────────────────────────────────────────
1. 访问 https://console.cloud.google.com
2. 新建项目 → 启用「Places API」
3. 创建 API 密钥 → 在 admin.html 点「⚙ API 设置」粘贴
4. 每月 $200 免费额度，日常用量完全够用
5. 设置后，「导入门店」时可自动填写营业时间、简介、分类


【门店图片说明】
───────────────────────────────────────────────
- 把图片放入 concierge/images/ 文件夹
- 在 admin.html 门店卡片「图片」字段填写：images/文件名.jpg
- 支持本地路径或外部 URL（如 Unsplash）
- 建议尺寸：宽至少 200px，高至少 220px，JPG/PNG 均可


【分类说明】
───────────────────────────────────────────────
  spa       → 显示为「SPA」
  dining    → 显示为「餐厅」
  transfer  → 显示为「接送机」
  whisky    → 显示为「酒吧」
  kimono    → 显示为「体验」


【搜索功能说明】
───────────────────────────────────────────────
支持模糊搜索：
  搜「送机」「接机」都能找到「接送机」相关门店
  搜「SPA」「按摩」「spa」均可
  搜索范围包括：店名、地区、描述、标签、分类名称
